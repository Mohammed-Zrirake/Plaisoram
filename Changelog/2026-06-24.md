# Changelog - 2026-06-24

## Project Overview & Technologies Discovered

Based on the initial scan of the project structure (`Plaisoram_Folder_Structure.md`), the following technologies and architectural choices have been identified in the Plaisoram monorepo:

### 1. Web Application (`plaisoram_web`)
The web application is built with a modern React/Next.js stack:
- **Framework**: Next.js (App Router, inferred from `app/` directory).
- **Language**: TypeScript (`.ts`, `.tsx`, `tsconfig.json`).
- **Package Manager**: pnpm (using workspaces, `pnpm-workspace.yaml`).
- **UI & Styling**: 
  - `shadcn/ui` or similar accessible component library (inferred from `components/ui/` containing many primitive components like `button.tsx`, `dialog.tsx`, `alert.tsx`, and `components.json`).
  - CSS with PostCSS (`postcss.config.mjs`, `global.css`).
- **Tooling**: Biome for formatting/linting (`biome.json`).
- **Internationalization (i18n)**: Likely `next-intl` or similar (`messages/en.json`, `messages/fr.json`, `i18n/request.ts`).
- **Features**: Authentication (login/signup), Dashboard (apps, canvas, devices, media, playlists, schedules, settings).

### 2. Backend Server (`Plaisoram_Server`)
The backend is a robust PHP/Symfony application:
- **Language**: PHP.
- **Framework**: Symfony (`symfony.lock`, `bin/console`, `Kernel.php`).
- **Dependency Management**: Composer (`composer.json`, `composer.lock`).
- **Database & ORM**: Doctrine (`doctrine.yaml`, `migrations/`, `Entity/` directories).
- **Authentication & Security**: JWT Authentication (`lexik_jwt_authentication.yaml`, `gesdinet_jwt_refresh_token.yaml`).
- **Real-time / Async**: Mercure for real-time updates (`mercure.yaml`), Symfony Messenger for async tasks (`messenger.yaml`).
- **Testing**: PHPUnit (`phpunit.dist.xml`, `tests/`).
- **Modules**: Device, Media, Playlist, Schedule, User, and Shared domain/infrastructure separation (suggesting a Domain-Driven Design approach).

### 3. Media Player Application (`Plaisoram_Player`)
The player application is a native Android app:
- **Platform**: Android.
- **Language**: Kotlin (`.kt` files).
- **Build System**: Gradle with Kotlin DSL (`build.gradle.kts`, `libs.versions.toml`).
- **UI Framework**: Jetpack Compose (`ui/components/`, `Theme.kt`, `Color.kt`).
- **Local Database**: Room Database (`AppDatabase.kt`, `dao/`, `entity/`).
- **Architecture**: Clean Architecture / MVVM (layers: `data`, `domain`, `presentation`, `di` for Dependency Injection).
- **Features**: Background Sync (`SyncWorker.kt`, `DownloadWorker.kt`), Multi-zone layout rendering (`MultiZoneLayout.kt`, `ZonedLayoutRenderer.kt`, `ImagePlayer.kt`, `VideoPlayer.kt`), Widgets (News, Weather).
