## Création de Champs Personnalisés (Key / Value)

> Formulaire simple pour créer une variable : un Nom (ex: prix_doliprane ), une Valeur (ex: 15 DH ), et une Description.

---

## L'Intégration API / ERP (Le pont vers Sobrus)

> Ce module de variables doit avoir des "Webhooks" ou une API ouverte. C'est ici que l'ERP (Sobrus) va envoyer automatiquement les prix en temps réel pour mettre à jour la valeur.
